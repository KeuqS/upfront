## Profiling

### `upfront.report.profile(root: pathlib.Path | str = '.', *, home: pathlib.Path | None = None, launch: bool = False, only: collections.abc.Iterable[str] | None = None, timeout: float = 20) -> upfront.report.Report`

Library entry point: discover configs under ``root`` and measure them.

``launch=False`` (the default) never starts a process or opens a connection; servers are
reported as ``skipped``. See ADR-0004.

### `upfront.report.profile_tools_file(path: pathlib.Path, *, only: collections.abc.Iterable[str] | None = None) -> upfront.report.Report`

Measure a saved ``tools/list`` JSON (``{"tools": [...]}`` or a list) for each client.

Dataclass with fields: `root, tokenizer, harnesses`.

### `upfront.report.HarnessReport`

Dataclass with fields: `harness, servers, skills_count, skills_metadata_tokens, skills_body_tokens, instructions, findings, errors`.

### `upfront.report.ServerUsage`

Dataclass with fields: `name, scope, transport, target, source, status, error, tools`.

### `upfront.report.ToolUsage`

Dataclass with fields: `name, tokens`.

### `upfront.report.FileUsage`

Dataclass with fields: `path, tokens`.

## Fetching

### `upfront.fetch.fetch_all(specs: list[upfront.discover.ServerSpec], *, timeout: float = 20, concurrency: int = 4) -> list[upfront.fetch.ServerResult]`

Fetch every server, launching each distinct command/URL once. Order matches ``specs``.

### `upfront.fetch.fetch_one(spec: upfront.discover.ServerSpec, timeout: float = 20) -> upfront.fetch.ServerResult`

Fetch one server's tools. Never raises: failures become ``status="error"``.

### `upfront.fetch.ServerResult`

Dataclass with fields: `spec, status, tools, error`.

## Compatibility rules

| id | harness | severity | rule | source |
|---|---|---|---|---|
| `openai-tool-name` | codex | error | OpenAI function names allow a-z, A-Z, 0-9, _ and -, up to 64 characters | [source](https://github.com/openai/openai-python/blob/main/src/openai/types/shared_params/function_definition.py) |
| `anthropic-tool-name` | claude-code | error | Claude tool names must match ^[a-zA-Z0-9_-]{1,128}$ after the mcp__&lt;server>__ prefix | [source](https://platform.claude.com/docs/en/agents-and-tools/tool-use/define-tools) |
| `gemini-tool-name` | gemini-cli | error | Gemini function names start with a letter or _; then a-zA-Z0-9_.:-, up to 128 | [source](https://github.com/googleapis/python-genai/blob/main/google/genai/types.py) |
| `claude-ref-params` | claude-code | warning | Parameters defined through $ref are sent to the server as JSON strings | [source](https://github.com/anthropics/claude-code/issues/18260) |

| `codex-skills-budget` | codex | warning | Codex caps the initial skills list at 2% of the context window (8,000 characters when the window is unknown) and shortens or drops skills beyond it | [source](https://learn.chatgpt.com/docs/build-skills) |
